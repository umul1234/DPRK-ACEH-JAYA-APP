# DPRK Aceh Jaya — Portal Informasi

Portal Streamlit dengan gaya portal pemerintahan modern, terinspirasi pola
informasi/layanan portal pemerintah daerah.

## Menjalankan lokal

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy ke Streamlit Community Cloud

1. Buat repository GitHub.
2. Upload `app.py` dan `requirements.txt`.
3. Buka Streamlit Community Cloud.
4. Pilih repository tersebut.
5. Set Main file path ke `app.py`.
6. Deploy.

## Struktur

- `app.py` — aplikasi utama
- `requirements.txt` — dependency
- `README.md` — panduan

Catatan:
Desain mengambil inspirasi struktur portal pemerintahan modern, tetapi identitas,
konten, logo, dan aset dibuat khusus untuk DPRK Aceh Jaya.
